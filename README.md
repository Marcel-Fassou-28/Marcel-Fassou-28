### 🌟 Featured Project - Job Watcher

**An AI-driven job search platform for students**, where a fine-tuned NLP model — not a rule engine — decides whether a job offer is suited for students.

- 🔍 Automated multi-source job scraping (Playwright)
- 🤖 **CamemBERT** (French BERT) fine-tuned locally with Hugging Face Transformers for binary classification
- 📊 Semi-automatic labeling pipeline (weighted heuristic rules + targeted manual review)
- 🔁 Periodic retraining pipeline as new data is collected
- 💻 Full-stack app: **Angular** frontend + **FastAPI** backend + **MongoDB**
- 🤖 **Telegram bot** with digest subscriptions (geographic filtering, configurable frequency, e-mail verification)
- 📬 Automated alerts (Telegram + e-mail) on new relevant offers

**Result:** 98% accuracy on a rigorously deduplicated test set (no train/test leakage), with strong precision/recall balance on the minority "student job" class.

This project pushed me through every layer of a real ML system in production: data cleaning pitfalls (duplicates, class imbalance, data leakage), model fine-tuning and honest evaluation, and full-stack integration from scraper to end-user notification.
